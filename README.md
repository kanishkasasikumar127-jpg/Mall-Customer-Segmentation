# Mall Customer Segmentation

## Project Overview

This project uses Machine Learning to segment mall customers into different groups based on their age, annual income, and spending score.

## Machine Learning Algorithm

- K-Means Clustering
- StandardScaler
- PCA
- Elbow Method

## Dataset

The dataset contains customer information such as:

- Customer Age
- Annual Income
- Spending Score

## Project Workflow

1. Load the dataset
2. Explore the data
3. Select relevant features
4. Standardize the features
5. Find the optimal number of clusters using the Elbow Method
6. Apply K-Means Clustering
7. Visualize customer segments
8. Apply PCA for visualization

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Files

- `mall_customers.csv` - Dataset

## Conclusion

This project demonstrates how K-Means Clustering can be used to identify different customer segments based on customer characteristics and spending behavior.
